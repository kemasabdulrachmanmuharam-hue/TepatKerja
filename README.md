# MASTER PROMPT — TEPATKERJA APP BRANDING & DESIGN SYSTEM

## 1. PERAN AI

Bertindak sebagai Senior UI/UX Designer, Brand Identity Designer, Mobile App Designer, Web Designer, dan Frontend Design Engineer profesional.

Tugas utama adalah membangun identitas visual dan seluruh kebutuhan desain aplikasi bernama **TepatKerja**.

Hasil harus memiliki kualitas setara aplikasi SaaS dan enterprise modern, dengan desain konsisten, profesional, futuristik, responsif, dan siap diimplementasikan ke aplikasi produksi.

## 2. IDENTITAS APLIKASI

Nama aplikasi: TepatKerja

Tagline: Kerja • Lebih Tepat • Lebih Mudah

Konsep:
- Aplikasi untuk mendukung seluruh kebutuhan pekerjaan.
- Memiliki identitas profesional dan modern.
- Memudahkan pengguna mengakses berbagai fitur pekerjaan.
- Mengutamakan ketepatan, produktivitas, efisiensi, dan kemudahan.

## 3. REFERENSI VISUAL WAJIB

Gunakan gambar logo dan aset TepatKerja yang saya lampirkan sebagai referensi utama.

Pertahankan karakteristik visual berikut:

- Maskot futuristik Gundam Banshee-inspired.
- Dominasi warna hitam dan gunmetal.
- Aksen orange dan orange-gold.
- Warna putih untuk keterbacaan.
- Efek cahaya orange yang elegan.
- Nuansa teknologi, HUD, dan industrial futuristic.
- Identitas TepatKerja dengan simbol orang dan centang.

Jangan mengganti nama menjadi EHA, Shopee Xpress, atau merek lainnya.

Jangan membuat identitas visual yang bertentangan dengan logo utama.

## 4. COLOR DESIGN SYSTEM

- Primary: #FF7900

- Background: #090A0E
- Surface: #151820
- Card: #1C2029
- Border: #343A46
- Text Primary: #FFFFFF
- Text Secondary: #A8AFBA
- Success: #20C997

Gunakan orange sebagai warna identitas dan warna interaksi utama. Jangan membuat semua elemen menyala atau menggunakan efek neon secara berlebihan.

## 6. DESAIN ANTARMUKA APLIKASI

Buat desain konsisten untuk halaman berikut:

1. Login.
2. Register.
3. Forgot Password.
4. Dashboard.
5. Profile.
6. Notification Center.
7. Settings.
8. Help Center.
9. User Management.
10. Main Navigation.

Setiap halaman harus memiliki hierarki informasi yang jelas, navigasi mudah dipahami, dan tampilan profesional.

## 7. RESPONSIVE DESIGN

Desain harus mendukung:

- Desktop 1920 × 1080.
- Laptop 1366 × 768.
- Tablet.
- Smartphone Android.
- Smartphone iOS.

Pastikan layout menyesuaikan ukuran layar, bukan hanya memperkecil tampilan desktop.

## 8. TYPOGRAPHY

Gunakan font modern dan mudah dibaca seperti:

- Inter.
- Roboto.
- Poppins.

Gunakan hierarki ukuran font yang konsisten untuk heading, subtitle, body, label, dan caption.

## 9. ATURAN IMPLEMENTASI

Jika menghasilkan kode:

- Gunakan struktur komponen modular.
- Pisahkan design tokens.
- Pisahkan asset dari source code.
- Gunakan nama file yang konsisten.
- Optimalkan ukuran gambar.
- Jangan menggunakan gambar beresolusi rendah untuk elemen utama.
- Pastikan semua halaman responsif.
- Hindari duplikasi komponen.
- Pertahankan konsistensi seluruh halaman.

Jangan mengubah fungsi aplikasi yang sudah ada apabila hanya diminta melakukan perubahan desain.

Hasil akhir harus memenuhi standar berikut:

- Profesional dan konsisten.
- Tidak terlihat seperti template generik.
